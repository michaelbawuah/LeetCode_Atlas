# 433 · Minimum Genetic Mutation

[Problem](https://leetcode.com/problems/minimum-genetic-mutation/) · Medium

## Idea and approach

BFS explores only one-position substitutions present in the bank and counts mutations as edges.

**Baseline:** Build all pairwise Hamming-distance edges in O(B²L) time and search that graph.

## Why it works

Every permitted mutation is generated by replacing its changed position. Queue distances increase layer by layer, making the first target arrival minimal. Marking a gene once is safe because later arrivals cannot use fewer mutations. B is bank size plus the start and L is gene length, fixed at eight by the platform.

## Complexity

O(B L^2) expected for fixed alphabet time. O(B L) auxiliary space. These bounds describe the submitted implementation, excluding fixture-adapter allocations. Inputs are not modified.

## Counterexample and checks

An end gene outside the bank cannot be introduced merely because it differs by one character. Named fixtures cover different structural boundaries. An independent bounded reference accompanies deterministic generated inputs in `test_properties.py`; `parity.py` supplies varied inputs for the shared language checks.

**Follow-up:** Reconstruct a shortest mutation sequence rather than only its length.

## Python and C++23 comparison

C++ accepts gene strings by reference and copies bank strings into an unordered set. Its queue and visited set own discovered gene strings, giving expected O(B L²) time and O(B L) space; L is fixed at eight. The original bank remains unchanged.
